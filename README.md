# Expense Tracker

A responsive Expense Tracker Web Application built using HTML, CSS, and JavaScript.

## Features

- Add Expenses
- Delete Expenses
- Search Expenses
- Filter by Category
- Monthly Summary
- Local Storage
- Dark Mode
- Responsive Design
- Separate Date and Time Inputs
- Modern Minimal UI

## Tech Stack

- HTML5
- CSS3
- JavaScript
